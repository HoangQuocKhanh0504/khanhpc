🔍 Xem trước repository

🗑️ Xoá nhiều repository GitHub

🔢 Đã chọn: 0 📦 Tổng: 0

📘 Hướng dẫn lấy Personal Access Token (PAT)

  1. Truy cập https://github.com/settings/tokens
  2. Nhấn Generate new token
  3. Chọn Generate new token (classic)
  4. Đăng nhập GitHub
  5. Nhập tên, chọn No expiration
  6. Tích quyền:
    • repo (tất cả mục con)
    • delete_repo
  7. Nhấn Generate token
  8. Sao chép token ngay
  9. Bắt đầu sử dụng web(nếu không biết có thể xem)

📖 Hướng dẫn sử dụng web

  1. Nhập GitHub username và PAT
  2. Nhấn nút 📂 Tải danh sách repo
  3. Tích chọn repo cần xoá
  4. Nhấn nút ❌ Xoá tất cả repo đã chọn
  5. Nếu chưa có PAT, nhấn 📘 Hướng dẫn lấy PAT
