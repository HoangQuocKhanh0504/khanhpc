Danh Sách Thư Viện Python

numpy

Hỗ trợ tính toán mảng, đại số tuyến tính, biến đổi Fourier, v.v.

pandas

Phân tích dữ liệu với cấu trúc DataFrame giống bảng tính Excel.

matplotlib

Vẽ biểu đồ 2D như line, bar, scatter,... dễ dàng.

seaborn

Vẽ biểu đồ thống kê đẹp mắt dựa trên matplotlib.

scikit-learn

Thư viện học máy phổ biến cho phân loại, hồi quy, phân cụm,...

tensorflow

Học sâu và trí tuệ nhân tạo của Google, hỗ trợ GPU.

keras

Xây dựng mô hình học sâu dễ dàng, API cao của TensorFlow.

pytorch

Framework học sâu mạnh mẽ của Facebook, dynamic graph.

xgboost

Mô hình tăng cường độ dốc, tối ưu cho Kaggle.

lightgbm

Boosting rất nhanh và nhẹ, của Microsoft.

catboost

Boosting tối ưu cho dữ liệu phân loại, của Yandex.

flask

Web framework nhỏ gọn, linh hoạt.

django

Framework mạnh mẽ để xây dựng web đầy đủ tính năng.

fastapi

API nhanh, hỗ trợ async, tự động sinh docs.

requests

Gửi HTTP request cực kỳ đơn giản.

httpx

HTTP client hỗ trợ async.

beautifulsoup4

Trích xuất dữ liệu HTML dễ dàng.

scrapy

Framework crawl dữ liệu mạnh mẽ.

sqlalchemy

ORM phổ biến để kết nối cơ sở dữ liệu SQL.

pymongo

Kết nối Python với MongoDB.

nltk

Xử lý ngôn ngữ tự nhiên cổ điển, nhiều công cụ.

spacy

NLP tốc độ cao, thích hợp cho sản phẩm thực tế.

gensim

Mô hình chủ đề, word2vec, biểu diễn văn bản.

textblob

Phân tích cảm xúc, từ loại dễ dùng.

pytest

Kiểm thử tự động đơn giản và mạnh mẽ.

mock

Tạo đối tượng giả trong unit test.

coverage

Đo độ bao phủ mã của test.

tox

Kiểm thử trên nhiều phiên bản Python.

joblib

Lưu mô hình, xử lý song song đơn giản.

openpyxl

Đọc ghi file Excel (xlsx).

xlrd

Đọc dữ liệu từ file Excel (.xls, .xlsx).

xlwt

Ghi dữ liệu vào file Excel (.xls).

openai

Tương tác với API OpenAI như ChatGPT, DALL·E.

transformers

Thư viện NLP của HuggingFace, hỗ trợ BERT, GPT, T5,...

sentence-transformers

Embedding câu dùng BERT, hiệu quả cao.

langchain

Xây dựng ứng dụng AI với LLM dễ dàng.

faiss-cpu

Tìm kiếm gần đúng (ANN) với tốc độ cao.

weaviate-client

Kết nối với cơ sở dữ liệu vector Weaviate.

pinecone-client

Tương tác với Pinecone vector database.

supabase

Kết nối ứng dụng Python với Supabase backend.

firebase-admin

Quản lý Firebase từ server-side.

streamlit

Tạo giao diện web nhanh chóng cho dự án ML.

gradio

Tạo UI tương tác trực tiếp cho mô hình AI.

dash

Xây dựng dashboard tương tác bằng Python.

plotly

Biểu đồ tương tác đẹp, hỗ trợ 3D.

bokeh

Vẽ biểu đồ tương tác động cho trình duyệt.

altair

Biểu đồ thống kê với cú pháp đơn giản, đẹp.

geopandas

Xử lý dữ liệu không gian (GIS) với pandas.

folium

Vẽ bản đồ tương tác với Leaflet.js.

shapely

Xử lý hình học (giao, giao cắt, vùng bao,...).

pillow

Xử lý ảnh cơ bản như crop, resize, filter.

opencv-python

Xử lý ảnh/video mạnh mẽ với OpenCV.

imageio

Đọc ghi ảnh và video đơn giản.

pyautogui

Tự động hóa chuột, bàn phím, màn hình.

keyboard

Ghi nhận và điều khiển bàn phím.

mouse

Điều khiển và lắng nghe sự kiện chuột.

pyttsx3

Chuyển văn bản thành giọng nói offline.

speechrecognition

Nhận diện giọng nói từ mic hoặc file.

pydub

Xử lý âm thanh, hỗ trợ nhiều định dạng file.

moviepy

Chỉnh sửa video, xử lý video mạnh mẽ.

scipy

Thư viện khoa học tính toán, giải quyết bài toán toán học phức tạp.

optuna

Tối ưu hóa siêu tham số cho mô hình học máy.

hyperopt

Tối ưu hóa siêu tham số với thuật toán bayesian optimization.

tqdm

Hiển thị tiến độ vòng lặp.

pickle

Chuyển đối tượng Python thành dữ liệu có thể lưu trữ và tải lại.

Thư viện cơ sở dữ liệu SQLite cho Python.
